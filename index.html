Field guide

How it works

The Base

Lights the ground around it and powers everything wired to it. Lose it and the run is over. Your score is the number of waves you hold.

HP
Light
Reach
  • Power runs by cable from the Base, server to server. You can only build where a cable reaches.
  • A building only works while it’s wired in. If a server goes out, everything past it loses power too.
  • Turrets and missiles only hit bots in the light.
